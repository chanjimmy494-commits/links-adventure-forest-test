LINK'S ADVENTURE - FOREST WALKING PROTOTYPE

Windows: Extract ZIP, double-click START_WINDOWS.bat. If Python is not installed, install Python 3 or serve the folder using another local web server.
Mac/Linux: run sh START_MAC_LINUX.sh then open http://localhost:8765/examples/html/index.html

Move with WASD / arrow keys. C toggles collision overlay. Explore 4 connected forest cells.

Uses licensed Tiny Realms Forest Map Kit assets and supplied Basic Hero and Blacksmith sprites. Not a full Link's Adventure game.
